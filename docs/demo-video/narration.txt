# 演示视频口播稿（提词器版）
# 用法：另开一个文本窗口/手机提词器，按时间码念。方括号里是操作提示，不要念出来。
# 语速：每分钟约 210 字；每段之间留 1–2 秒给画面。
# 提示：口播比镜头槽略短是正常的，剩下的时间留给真实操作（输入、上传、加载）。

[0:00] 大家好，我是侯学强，下面演示我的毕业设计——校园论坛系统。

[0:08] 系统分为三部分：Spring Boot 3 写的论坛后端、Vue 3 前端，以及一个独立的 Python 成绩查询服务。业务数据在 MySQL，Redis 负责缓存、限流和 JWT 黑名单，RabbitMQ 异步发邮件，图片存在 MinIO。三个服务已经启动，我们先看身份认证。

[0:40] 注册要填用户名、邮箱和两次密码，密码用 BCrypt 存储。发送验证码后，后端把任务丢进 RabbitMQ，监听器再发邮件，所以接口不用等 SMTP 返回。登录用 user 账号，勾选记住我，token 进 localStorage；不勾就进 sessionStorage，关掉浏览器就失效。这里退出登录，旧 token 会被写进 Redis 黑名单，过期时间就是 token 的剩余有效期，所以退出后立即失效。

[1:30] 进入帖子广场。顶部天气卡片按坐标或城市 ID 取和风天气，缓存一小时，避免每次刷新都打第三方；浏览器定位不可用时可以手动切换城市。下面是分类筛选和标题搜索，切分类只改 URL 参数、不跳路由，列表状态保留。列表用无限滚动，滚到底自动加载下一页，底部显示总条数。

[2:10] 发帖先选分类，选到失物招领会自动出现物品、地点、时间这些字段，这是分类模块的结构化扩展。标题和正文用 Quill 富文本编辑器，可以加粗、列表、插图。图片限制 5 MB，前端直传后端，后端再写 MinIO，返回相对路径，读取时带 30 天缓存。正文里的 HTML 由服务端重新清洗，不信任前端提交的内容。

[3:00] 这条帖子是 user 发的，我换一个账号看：手机号和微信是隐藏的，作者本人能看到全部，过滤发生在服务端。标题滚出视口后会出现吸顶导航。点赞和收藏是切换接口，数据库用帖子和用户的唯一索引防重复，新增点赞会给楼主发通知。

[3:40] 评论区在底部卡片里，支持富文本和插图。回复某一条时，前端把父评论 id 一起提交；后端用 quote 记录直接父级、root_id 记录顶层评论，读取时按顶层分页，再一次组装整棵树。最多 10 层，视觉上缩进 3 层。作者或楼主可以删除评论，删父评论会连整棵子树一起删掉。

[4:25] 通知分互动通知和系统通知两类，评论、回复、点赞、收藏都会触发，自己操作自己的帖子不会通知。消息列表支持单条已读和全部已读；管理端的置顶、锁定、屏蔽、禁言也会写一条系统通知。我的收藏按收藏时间倒序，可以直接取消。

[5:00] 三个分类模块复用同一套内容模型，共用帖子表和列表组件，差别只在分类配置和 extra 字段。失物招领记录物品、地点、时间和联系方式，作者可以标记“已找回”，列表和详情都会同步。校园活动有起止时间、地点和主办方。表白墙是匿名分类：列表里的作者 uid 一律为空，详情和评论只对作者本人显示身份，其他人看到的是“匿名同学”。

[5:45] 校园服务包括教务通知、我的课程表和在线图书馆。需要说明的是，学校没有开放教务和图书馆接口，这三块数据由管理员在后台维护，不是实时对接。通知支持分类、搜索、置顶和富文本详情；课程表是每个用户自己的，有周视图和列表两种展示，可以用 CSS Grid 按节次定位，也可以增删改；图书馆支持书目检索、详情和跳转外链。

[6:30] 用管理员账号登录后，右上角出现“管理后台”。帖子管理可以置顶、锁定、屏蔽、改分类和删除。锁定之后普通用户不能评论，作者也不能编辑；屏蔽的帖子只对管理员和作者可见。匿名帖在管理端能看到真实作者。分类管理支持增删改，分类 code 创建后不可修改，分类下还有帖子时不能删除。用户管理可以禁言、封禁和重置密码：禁言只拦截发帖和评论，封禁会让用户无法登录；这些操作都会给用户写一条系统通知。

[7:25] 最后是扩展的成绩查询服务。它是独立的 FastAPI 进程，模拟登录超星获取成绩，滑块用 ddddocr 识别。它故意不复用论坛的 JWT，超星会话过期不会把用户从论坛踢出去。登录后按学期懒加载，平均绩点按学分加权自算；查询成功会写快照，超星不可用时自动回落，并标记 offline。

[8:00] 最后看几个技术点。所有请求先经过 CORS、限流、JWT 三道过滤器，任何一环失败都直接写统一响应，不进 Controller。限流默认 2 秒 50 次，超过封 30 秒，快速刷新可以触发 429；业务层还有发帖 10 秒、评论 3 秒、图片每小时 20 次的限制。帖子列表在 Redis 缓存 2 分钟，写操作会主动清缓存。后端单元测试全部通过，前端生产构建正常。我的演示就到这里，谢谢各位老师。

# —— 备用句（现场忘词/需要拖时间时念） ——
# · 这个模块的接口统一返回 code、data、message 三段，前端按 code 统一处理 401、403、429。
# · 匿名不是把 uid 置空，而是分类上有一个 anonymous 标记，服务端按“是不是作者”决定返不返回身份。
# · 帖子的结构化字段存在 extra 这个 JSON 列里，服务端有白名单，最多 120 字。
# · 图片上传限制 5 MB、头像 100 KB 是写在 Controller 里的硬编码，不靠前端校验。
